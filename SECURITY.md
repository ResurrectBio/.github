# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any of our repositories, please report it responsibly.

**Please do not open a public issue.** Instead:

- Email your line manager with details of the vulnerability.
- Include steps to reproduce, the affected repository/version, and potential impact if known.

## What to Expect

1. We'll acknowledge your report and confirm we're investigating.
2. We'll work with you to understand the scope and validate the issue.
3. Once resolved, we'll coordinate on disclosure timing and, if you'd like, credit you for the find.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

_Adjust this table per-repo if a repo has a different support policy._

## Scope

This policy applies to all repositories under the ResurrectBio GitHub organisation unless a repo defines its own `SECURITY.md`, which takes precedence.
