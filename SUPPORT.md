# Support

Thanks for using or contributing to a Resurrect Bio repository. Here's where to go depending on what you need:

## Questions & General Help

- Post in Google Teams Dry Lab channel — this is faster than a GitHub issue and keeps issue trackers focused on actionable work.
- Check the repo's own `README.md` first — many common setup questions are answered there.

## Bug Reports

- Open an issue using the **Bug Report** template. Please don't report bugs in Google Teams only — we want them tracked.

## Feature Requests

- Open an issue using the **Feature Request** template, or bring it to your team's planning process if it's a larger idea.

## Security Issues

- Do **not** open a public issue. See `SECURITY.md` for how to report vulnerabilities privately.

## Something Else

- If you're not sure where something belongs, default to Google Teams Dry Lab channel and someone will point you in the right direction.
